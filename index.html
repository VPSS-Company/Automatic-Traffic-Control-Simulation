How the demo works

The main idea behind my Science Day project
📡
1. Check the queues

The lane sliders stand in for sensors that count the vehicles waiting on each road.

🧠
2. Pick a road

The demo compares the queue scores and gives the green light to the road with the highest priority.

🚘
3. Let traffic move

Some vehicles leave the selected queue. The system then checks the queues again for the next turn.
